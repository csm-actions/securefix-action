# Error: Creating a pull request isn't allowed for the given repository and branch.

This error occurs if you try to create a pull request with a commit pushed to another repository or branch, and the entries of the server configuration matching the repository and branch don't allow pull requests.

An entry without `pull_request` allows only pushing a commit directly.
To allow pull requests, set `pull_request: {}` to the entry.

```yaml
entries:
  - client:
      repositories:
        - suzuki-shunsuke/tfaction
    push:
      repositories:
        - suzuki-shunsuke/tfaction-docs
      branches:
        - "follow-up-*"
    pull_request: {}
```
